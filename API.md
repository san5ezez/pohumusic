# POHUMUSIC — ДОКУМЕНТАЦИЯ API (`API.md`)

Все эндпоинты серверной части PohuMusic доступны по базовому префиксу `/api/v1`.
Актуальная машиночитаемая спецификация OpenAPI 3.1.0 генерируется непосредственно из рабочего кода и доступна по адресу:
`GET /api/v1/openapi.json`

---

## 1. Аутентификация и заголовки

- `Authorization: Bearer <accessToken>` — передача JWT Access токена (срок жизни 15 минут).
- `X-Device-Id: <deviceId>` — уникальный идентификатор клиентского устройства для управления сессиями и синхронизации плеера.
- `X-Device-Name: <deviceName>` — человекочитаемое имя устройства (например, `MacBook Pro — Studio Monitor`).
- `Idempotency-Key: <uniqueKey>` — ключ идемпотентности для защиты мутирующих запросов (`PUT /player/state`, `PUT /player/queue`) от повторного выполнения при сетевых сбоях.

---

## 2. Полный реестр маршрутов `/api/v1`

### AUTH (`/api/v1/auth`)
| Метод | Маршрут | Описание |
| :--- | :--- | :--- |
| `POST` | `/api/v1/auth/register` | Регистрация (`email`, `username`, `password`, `displayName`). Пароль хэшируется в формате Argon2id-v1. |
| `POST` | `/api/v1/auth/login` | Вход по Email или Username. После 5 неудачных попыток аккаунт временно блокируется на 15 минут (`423 Locked`). |
| `POST` | `/api/v1/auth/logout` | Отзыв текущей сессии (`revokeAllDevices: true` отзывает все сессии пользователя). |
| `POST` | `/api/v1/auth/refresh` | Ротация Refresh токена. При попытке повторного использования старого токена вся цепочка (`token_family`) аннулируется. |
| `POST` | `/api/v1/auth/forgot-password` | Создание токена сброса пароля в D1. Если SMTP не настроен, честно возвращает `emailServiceConfigured: false`. |
| `POST` | `/api/v1/auth/reset-password` | Смена пароля по одноразовому токену и автоматический отзыв старых сессий. |
| `POST` | `/api/v1/auth/verify-email` | Подтверждение адреса электронной почты по токену. |
| `GET` | `/api/v1/auth/me` | Получение текущего пользователя, списка активных сессий/устройств и привязанных OAuth-аккаунтов (Google, Discord). |
| `GET` | `/api/v1/auth/oauth/:provider/start` | Инициализация OAuth 2.0 (Google / Discord) с сохранением криптографического `state` в Cloudflare KV. |
| `POST` | `/api/v1/auth/oauth/:provider/callback` | Проверка `state` из KV и завершение OAuth-авторизации на сервере (секреты никогда не передаются клиенту). |

### USERS (`/api/v1/users`)
| Метод | Маршрут | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/v1/users/me` | Профиль текущего пользователя, пользовательские предпочтения и использование квот (плейлисты `X/10`, история `Y/15`). |
| `PATCH` | `/api/v1/users/me` | Обновление профиля и настроек. Смена `username` разрешена не чаще 1 раза в 7 дней (`429 USERNAME_CHANGE_COOLDOWN`). Попытка передать поле `role` блокируется (`403 SELF_ROLE_MODIFICATION_FORBIDDEN`). |
| `DELETE` | `/api/v1/users/me` | Полное удаление аккаунта с каскадной очисткой всех 14 связанных таблиц в D1. |
| `GET` | `/api/v1/users/:username` | Публичный профиль пользователя и его открытые плейлисты. |
| `GET` | `/api/v1/users/:username/playlists` | Список публичных плейлистов пользователя. |

### MUSIC (`/api/v1/tracks`, `/api/v1/artists`, `/api/v1/albums`)
| Метод | Маршрут | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/v1/tracks/search` | Поиск треков (`?q=`, `?provider=all\|soundcloud\|youtube`, `?access=playable,preview,blocked`). Возвращает единый тип `Track[]`. |
| `GET` | `/api/v1/tracks/:id` | Метаданные трека (`sc_*` или `yt_*`) и объект `PlaybackInfo` с разрешённым режимом воспроизведения. |
| `GET` | `/api/v1/tracks/:id/related` | Связанные треки из провайдера. |
| `GET` | `/api/v1/artists/search` | Поиск исполнителей по всем провайдерам. |
| `GET` | `/api/v1/artists/:id` | Профиль исполнителя и его популярные треки. |
| `GET` | `/api/v1/albums/search` | Поиск альбомов и плейлистов провайдеров. |
| `GET` | `/api/v1/albums/:id` | Получение альбома вместе со списком треков. |

### FAVORITES (`/api/v1/library/favorites`)
| Метод | Маршрут | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/v1/library/favorites` | Список избранных треков пользователя. |
| `POST` | `/api/v1/library/favorites` | Идемпотентное добавление трека в избранное (`{ trackId }` или `{ track }`). |
| `DELETE` | `/api/v1/library/favorites/:trackId` | Удаление трека из избранного. |

### PLAYLISTS (`/api/v1/playlists`)
| Метод | Маршрут | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/v1/playlists` | Список плейлистов текущего пользователя. |
| `POST` | `/api/v1/playlists` | Создание плейлиста. Жёсткий лимит: максимум 10 плейлистов на пользователя (`400 PLAYLIST_LIMIT_EXCEEDED`). |
| `GET` | `/api/v1/playlists/:id` | Получение плейлиста и упорядоченного списка его треков. |
| `PATCH` | `/api/v1/playlists/:id` | Редактирование названия, описания и публичности (только владелец; поддержка `expectedVersion`). |
| `DELETE` | `/api/v1/playlists/:id` | Удаление плейлиста владельцем. |
| `POST` | `/api/v1/playlists/:id/tracks` | Идемпотентное добавление трека в плейлист. |
| `DELETE` | `/api/v1/playlists/:id/tracks/:trackId` | Удаление трека из плейлиста. |
| `POST` | `/api/v1/playlists/:id/share` | Генерация уникального `shareId` для публичного доступа к плейлисту. |
| `GET` | `/api/v1/playlists/public/:shareId` | Публичное получение расшаренного плейлиста по `shareId` с учётом счётчика открытий. |

### HISTORY (`/api/v1/history`)
| Метод | Маршрут | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/v1/history` | Получение истории прослушиваний (максимум 15 последних уникальных треков). |
| `POST` | `/api/v1/history` | Запись прослушивания (`trackId`, `listenedMs`, `wasSkipped`). Автоматически дедуплицирует трек и обрезает историю до 15 последних уникальных записей. |
| `DELETE` | `/api/v1/history` | Полная очистка истории прослушиваний пользователя. |

### RECOMMENDATIONS (`/api/v1/recommendations`)
| Метод | Маршрут | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/v1/recommendations` | Персональные рекомендации по параметрам `activity` (Просыпаюсь, В дороге, Работаю, Тренируюсь, Засыпаю), `character` (Любимое, Незнакомое, Популярное), `mood` (Бодрое, Весёлое, Спокойное, Грустное), `language` (Русский, Английский, Без разницы, Без слов). |
| `GET` | `/api/v1/recommendations/modes` | Полный каталог режимов рекомендаций на русском и английском языках. |
| `GET` | `/api/v1/recommendations/track/:id` | Отдельный механизм подбора похожих треков на основе реальных метаданных (общий исполнитель, жанр, теги, язык). |
| `POST` | `/api/v1/recommendations/feedback` | Отправка обратной связи (`like`, `dislike`, `skip`, `complete_listen`, `dismiss`), влияющей на последующую выдачу. |

### PLAYER (`/api/v1/player`)
| Метод | Маршрут | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/v1/player/state` | Получение состояния плеера и списка всех подключённых устройств пользователя. |
| `PUT` | `/api/v1/player/state` | Синхронизация состояния плеера с проверкой `expectedVersion` (`409 SYNC_VERSION_CONFLICT` при рассинхронизации) и автоматической постановкой на паузу остальных устройств при переключении активного устройства. |
| `GET` | `/api/v1/player/queue` | Получение текущей очереди воспроизведения из D1. |
| `PUT` | `/api/v1/player/queue` | Сохранение очереди воспроизведения с поддержкой `expectedVersion` и `Idempotency-Key`. |

### ADMIN (`/api/v1/admin`)
| Метод | Маршрут | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/v1/admin/statistics` | Сводная статистика пользователей, активных сессий, прослушиваний, источников, популярных треков и ошибок. |
| `GET` | `/api/v1/admin/users` | Список пользователей с фильтрацией по ролям (`user`, `moderator`, `admin`). |
| `PATCH` | `/api/v1/admin/users/:id` | Управление ролями и блокировкой пользователей (администратору запрещено менять собственную роль). |
| `GET` | `/api/v1/admin/errors` | Журнал ошибок провайдеров, срабатываний rate-limit, конфликтов синхронизации и событий безопасности. |
| `GET` | `/api/v1/admin/tracks/popular` | Топ треков с раздельным отображением `rawProviderPlayCount` и расчётного `calculatedSoundCloudHalvedDisplayMetric` (`raw / 2`). |
| `GET` | `/api/v1/admin/settings` | Чтение системных настроек платформы из D1. |
| `PATCH` | `/api/v1/admin/settings` | Обновление системных настроек платформы с записью в аудит-лог. |
